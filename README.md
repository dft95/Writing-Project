# Writing Project

A place to draft, organize, and refine writing projects.

## Getting Started

This repo is for storing and versioning writing work in progress. Each piece can live in its own file or folder, so it's important to keep names descriptive.

## Structure

- `drafts/` - work in progress pieces
- `notes/` - research notes and outlines

## Contributing

Feel free to open a PR with edits, notes, or new drafts.
